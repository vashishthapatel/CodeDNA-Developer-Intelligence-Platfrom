### **Color Palette**
```css
Primary:    #8B5CF6  /* Purple - Main accent */
Secondary:  #6366F1  /* Indigo - Gradient blend */

Background: #000000  /* Pure Black - Base */
Surface:    rgba(23, 23, 28, 0.6)  /* Glass cards */
Text:       #FFFFFF  /* White - Primary text */

Success:    #34D399  /* Green - Positive metrics */
Warning:    #FBBF24  /* Amber - Alerts */
Error:      #F87171  /* Red - Critical items */
```

### **Typography**
- **Font Family**: Inter (400-900 weights)
- **Hero Headings**: 3-6rem (responsive)
- **Section Titles**: 2.5-4rem
- **Body Text**: 1.125-1.5rem
- **Small Text**: 0.875rem
- **Font Smoothing**: Antialiased

### **Effects**
- **Glass Morphism**: backdrop-blur(12px)
- **Border Radius**: 12-32px (varies by component)
- **Transitions**: 0.3s ease (all interactions)
- **Shadows**: Colored glows with accent colors
- **Hover Lift**: -2px to -8px translateY
- **Hover Scale**: 1.05-1.1x
- **Gradient**: 135deg angle (primary → secondary)
