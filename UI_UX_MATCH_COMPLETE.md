## 🎭 Animation & Interaction Patterns

### Hover Effects (All Components)
```css
- transform: translateY(-2px) /* Card lift */
- scale: 1.05 /* Icon growth */
- border-color: accent/60 /* Glow */
- shadow: accent/20 /* Colored shadow */
```

### Gradient Text
```css
background: linear-gradient(118deg, #ffffff 18%, #a78bfa 62%, #6366f1 100%)
background-clip: text
```

### Glass Morphism
```css
background: rgba(23, 23, 28, 0.6)
backdrop-filter: blur(12px)
border: 1px solid rgba(255, 255, 255, 0.06)
```

### Card Hover States
```css
border-color: rgba(139, 92, 246, 0.3)
box-shadow: 0 8px 32px rgba(139, 92, 246, 0.15)
transform: translateY(-2px)
```
